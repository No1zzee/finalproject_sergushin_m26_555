# ValutaTrade Hub

ValutaTrade Hub — консольное приложение для управления виртуальным валютным портфелем и симуляции покупки и продажи валют.

Проект оформлен как Python-пакет `finalproject_sergushin_m26_555`.

## Возможности

- Регистрация пользователей и вход в систему.

- Хранение паролей в виде SHA-256-хеша с индивидуальной солью.

- Создание валютных кошельков при покупке.

- Покупка и продажа валют с проверкой суммы и остатка.

- Просмотр портфеля и его стоимости в выбранной базовой валюте.

- Получение прямых, обратных и кросс-курсов.

- Обновление курсов из CoinGecko и ExchangeRate-API.

- Хранение пользователей, портфелей, кеша и истории курсов в JSON.

- Журналирование операций и ошибок с ротацией файлов.

Поддерживаемые валюты: **USD, EUR, GBP, RUB, BTC, ETH, SOL**.

В симуляции покупка увеличивает баланс выбранной валюты, а продажа уменьшает его. Стоимость операции в USD выводится справочно. Автоматическое списание или зачисление USD при этих операциях не выполняется.

## Технологии

- Git — контроль версий.

## Установка

Необходимы Git и uv. Для установки зависимостей и обновления курсов требуется подключение к интернету.

Инструкция по установке uv: [официальная документация](https://docs.astral.sh/uv/getting-started/installation/).

В Windows uv можно установить командой:

```bash
winget install --id astral-sh.uv -e
```

После установки заново откройте терминал.

Следующие команды выполняются в Git Bash:

```bash
git clone https://github.com/No1zzee/finalproject_sergushin_m26_555.git
cd finalproject_sergushin_m26_555
uv python install 3.12
uv sync --locked
```

`uv sync --locked` создаёт виртуальное окружение и устанавливает проект с зависимостями согласно `uv.lock`.

## Настройка API-ключа

### ExchangeRate-API

1. Зарегистрируйтесь на [ExchangeRate-API](https://www.exchangerate-api.com/).

2. Получите персональный API-ключ.

3. Сохраните его в переменной окружения `EXCHANGERATE_API_KEY`.

Для постоянной настройки в Windows:

1. Найдите через поиск Windows пункт «Изменение переменных среды текущего пользователя».

2. В разделе переменных пользователя нажмите «Создать».

3. Укажите имя `EXCHANGERATE_API_KEY`.

4. В значение вставьте полученный ключ.

5. Сохраните настройку и перезапустите Git Bash. Если терминал открыт внутри редактора, перезапустите редактор.

Приложение автоматически читает ключ из окружения и подставляет его в адрес:

```text
https://v6.exchangerate-api.com/v6/ВАШ_КЛЮЧ/latest/USD
```

Ключ настраивается для установленной копии приложения. Пользователям валютного кошелька не требуется получать отдельные ключи.

### CoinGecko

Для использования клиент может обращаться к публичному API без ключа.

Если используется Demo API-ключ CoinGecko, его можно задать в переменной окружения `COINGECKO_API_KEY`.

Криптовалюты запрашиваются по идентификаторам `bitcoin`, `ethereum` и `solana`.

## Запуск

Выполняйте запуск из корня проекта: по умолчанию приложение использует относительные пути к настройкам, данным и журналам.

```bash
uv run valutatrade
```

Альтернативный запуск:

```bash
uv run main.py
```

После запуска появится приглашение:

```text
valutatrade>
```

Команды приложения вводятся в это приглашение.

## Команды

| Команда | Назначение |
|---|---|
| `register --username demo_user --password demo1234` | Зарегистрировать пользователя |
| `login --username demo_user --password demo1234` | Войти в систему |
| `buy --currency SOL --amount 2` | Увеличить баланс SOL на 2 |
| `sell --currency SOL --amount 1` | Уменьшить баланс SOL на 1 |
| `show-portfolio` | Показать портфель в USD |
| `show-portfolio --base EUR` | Показать стоимость портфеля в EUR |
| `get-rate --from BTC --to EUR` | Получить курс BTC к EUR |
| `update-rates` | Обновить курсы из обоих источников |
| `update-rates --source coingecko` | Обновить криптовалютные курсы |
| `update-rates --source exchangerate` | Обновить фиатные курсы |
| `show-rates` | Показать сохранённые курсы |
| `show-rates --currency BTC` | Показать курс BTC |
| `show-rates --top 2` | Показать две самые дорогие криптовалюты из кеша |
| `show-rates --base EUR` | Пересчитать отображаемые курсы в EUR |
| `help` | Показать справку |
| `exit` | Завершить работу |

Для справки по отдельной команде используйте, например:

```text
buy --help
```

### Пример сеанса

Сначала обновите курсы, затем выполните операции:

```text
register --username demo_user --password demo1234
login --username demo_user --password demo1234
update-rates
buy --currency SOL --amount 2
sell --currency SOL --amount 1
show-portfolio
get-rate --from BTC --to EUR
exit
```

После покупки и продажи в кошельке останется 1 SOL.

Регистрация не выполняет вход автоматически. После повторного запуска приложения необходимо снова выполнить `login`; сохранённые пользователи и балансы остаются в JSON.

Приведённый пароль предназначен только для учебного примера.

### Обработка ошибок

Приложение сообщает о недостаточном остатке, неизвестной валюте, некорректной сумме, ошибке входа и проблемах с курсами.

Примеры:

```text
sell --currency SOL --amount 100
buy --currency SOL --amount -1
get-rate --from ABC --to USD
```

После обработки таких ошибок приложение продолжает принимать команды.

## Хранение данных и TTL

- `users.json` — пользователи, хеши паролей, соли и даты регистрации.

- `portfolios.json` — портфели и балансы кошельков.

- `rates.json` — последние курсы для Core Service.

- `exchange_rates.json` — история измерений Parser Service.

Начальный формат кеша:

```json
{
  "pairs": {},
  "last_refresh": null
}
```

После обновления каждая валютная пара содержит курс, время получения и источник.

Core Service читает локальный кеш. Он не отправляет запросы к внешним API при выполнении торговых операций.

TTL задаётся параметром `rates_ttl_seconds` в секции `[tool.valutatrade]` файла `pyproject.toml`. Текущее значение — **300 секунд**.

Если нужный курс отсутствует или устарел, приложение предлагает выполнить:

```text
update-rates
```

Команда `show-rates` позволяет увидеть устаревшие записи с соответствующим статусом.

## Parser Service

Источники данных:

- [CoinGecko](https://www.coingecko.com/en/api) — BTC, ETH и SOL.

- [ExchangeRate-API](https://www.exchangerate-api.com/) — EUR, GBP и RUB.

Клиенты приводят ответы к общему формату пар `CODE_USD`. Курсы ExchangeRate-API, полученные относительно USD, обращаются для расчёта стоимости единицы валюты в USD.

Обновление можно выполнить командой `update-rates` внутри приложения или отдельным процессом из Git Bash.

Однократное обновление:

```bash
uv run python -m valutatrade_hub.parser_service.scheduler --once
```

Периодическое обновление:

```bash
uv run python -m valutatrade_hub.parser_service.scheduler
```

По умолчанию период составляет 3600 секунд. Планировщик запускается отдельно и останавливается сочетанием `Ctrl+C`.

Параметр `--interval` задаёт период в секундах, а `--source` ограничивает обновление одним источником.

В текущей конфигурации период планировщика больше TTL кеша. Поэтому при истечении TTL перед операциями потребуется ручное обновление через `update-rates`.

При ошибке одного источника обновление продолжает работу с данными другого и выводит предупреждение.

Кеш и история записываются через временные файлы с последующей заменой целевых файлов.

## Настройки и журналы

Основные настройки находятся в секции `[tool.valutatrade]` файла `pyproject.toml`. Параметры API — в `parser_service/config.py`.

Переменные окружения:

| Переменная | Назначение |
|---|---|
| `EXCHANGERATE_API_KEY` | Ключ ExchangeRate-API |
| `COINGECKO_API_KEY` | Необязательный Demo API-ключ CoinGecko |
| `VALUTATRADE_CONFIG` | Путь к файлу конфигурации TOML |
| `VALUTATRADE_DATA_DIR` | Каталог данных |
| `VALUTATRADE_LOG_DIR` | Каталог журналов |

По умолчанию журналы создаются в `logs/`:

- `actions.log` — пользовательские операции.

- `parser.log` — обновление курсов.

Используется формат JSON и ротация: максимальный размер файла — 1 МиБ, количество резервных файлов — 3.
